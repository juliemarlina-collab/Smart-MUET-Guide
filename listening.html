How to Complete SmartListening

  1. Select a listening session and part.
  2. Read the questions before playing the audio/script.
  3. Use the note box to write keywords only, not full sentences.
  4. Select the best answer for each question.
  5. Submit to reveal answer explanations and transcript.
  6. Review distractors and signal words after submission.
Student input required: Keyword notes + MCQ answers.
Listening note example: “Wed / 4.30 / LH2 / bring earphones”.
